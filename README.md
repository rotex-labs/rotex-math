# rotex-math

Math and color crates for Rotex.

| Package | Path |
|---------|------|
| `rotex-math` | `crates/rotex-math` |
| `rotex-color` | `crates/rotex-color` |

`rotex-color` depends on `rotex-math` by path inside this repo. Each package keeps its own version and its own release tag (`rotex-math-v0.1.0`, `rotex-color-v0.1.0`).
